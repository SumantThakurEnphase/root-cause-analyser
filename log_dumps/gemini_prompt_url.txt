## Data Debugging Principles

### Missing Data
- Null or undefined objects when querying the database.
- Missing records that should have been created by a previous pipeline step.
- Empty arrays where geometry, proposals, or project data is expected.

### Corrupt Data
- Schema migration issues: old records missing new required fields.
- Partial writes: transaction not completed, leaving data in an inconsistent state.
- Encoding issues: garbled strings, incorrect coordinate systems.

### Stale Data
- Redis cache returning outdated values after a DB update.
- CDN serving old assets after a deployment.
- Browser caching stale API responses.

function getCommercialProjectPermitPlanCharge(systemSize, permitService) {
	let permitPlanCharge = 0;
	if (systemSize > 750) {
		permitPlanCharge = permitService.commercial_permit_751_kw_to_1_mw;
	} else if (systemSize > 500) {
		permitPlanCharge = permitService.commercial_permit_501_kw_to_750_kw;
	} else if (systemSize > 400) {
		permitPlanCharge = permitService.commercial_permit_401_kw_to_500_kw;
	} else if (systemSize > 300) {
		permitPlanCharge = permitService.commercial_permit_301_kw_to_400_kw;
	} else if (systemSize > 250) {
		permitPlanCharge = permitService.commercial_permit_251_kw_to_300_kw;
	} else if (systemSize > 200) {
		permitPlanCharge = permitService.commercial_permit_201_kw_to_250_kw;
	} else if (systemSize > 100) {
		permitPlanCharge = permitService.commercial_permit_101_kw_to_200_kw;
	} else if (systemSize > 50) {
		permitPlanCharge = permitService.commercial_permit_51_kw_to_100_kw;
	} else if (systemSize > 30) {
		permitPlanCharge = permitService.commercial_permit_31_kw_to_50_kw;
	} else if (systemSize > 0) {
		permitPlanCharge = permitService.commercial_permit_up_to_30_kw;
	} else {
		permitPlanCharge = 0;
	}
	return permitPlanCharge;
}
